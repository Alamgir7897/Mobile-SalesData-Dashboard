##  Overview

This project is an interactive Power BI dashboard designed to analyze mobile phone sales data and provide actionable business insights. The dashboard enables users to explore sales performance through dynamic filters and visualizations.

## ✨ Features

- 📈 KPI Cards for Total Sales, Total Quantity, Average Sales, and Transactions

- 🎛️ Interactive Slicers for Month, Brand, and Payment Method
  
- 🗺️ City-wise Sales Analysis using Map Visualization
  
- 📅 Monthly Sales Trend Analysis
  
- 📱 Top-Selling Mobile Models Analysis
  
- 💳 Payment Method Distribution
  
- ⭐ Customer Rating Analysis
  
- 🏷️ Brand-wise Sales Performance Tracking
